
# 📘 Assignment: Games in Python

## 🎯 Objective

Practice Python strings, loops, conditionals, user input, and random selection by building a classic Hangman word-guessing game.

## 📝 Tasks

### 🛠️ Create the Hangman Game

#### Description

Build a Hangman game where players guess letters to reveal a hidden word before they run out of attempts.

#### Requirements

Completed program should:

- Randomly select a word from a predefined list.
- Accept letter guesses from the player.
- Show the current progress using underscores, such as `_ _ _`.
- Track the number of incorrect guesses remaining.
- End when the player guesses the word or runs out of attempts.
- Display a clear win or lose message.
